사용 설명서별일없지? · 요점만
방장 한 사람이 먼저 가족방을 만들고,
가족은 초대 코드로 들어와요.
① 방장이 만들기→② 초대 코드 보내기→③ 가족은 코드 입력

방장먼저 할 일

  1. 앱을 열고 홈 화면에 추가, 그다음부터 해님 아이콘으로 열기아이폰 Safari: 공유 → 홈 화면에 추가 · 갤럭시 Chrome: ⋮ → 홈 화면에 추가
  2. 첫 화면 맨 아래 방장만 · 새 가족방 만들기 → 이름·사는 곳 적고 만들기
  3. 가족 편집 → + 가족 초대하기 → 코드를 카톡으로 한 사람씩 보내기코드는 48시간 안에, 한 사람만 쓸 수 있어요. 최대 8명.

가족초대받은 사람

  1. 카톡의 초대 링크를 열고 홈 화면에 추가아이폰은 Safari로 열어야 해요. 코드 6자리는 적어 두세요.
  2. 해님 아이콘으로 열고, 첫 화면 "초대 코드로 들어가기"에 코드·이름 넣기
  3. 알림 켜기 → 허용

가족은 "새 가족방 만들기"를 누르지 마세요. 누르면 우리 가족방에 들어올 수 없어요.

모두매일 쓰기

  1. 묻기: 가족 얼굴 고르고 음성 없이 간단히 물어보기 또는 간단한 음성으로 물어보기음성은 누르고 말한 뒤 다시 누르면 보내져요 (1분까지).
  2. 답하기: 맨 위에 해님이 움직이면 별일 없어요 터치
  3. 소식: 회색 안부 · 분홍 받은 음성 · 파랑 보낸 음성목소리는 90일 뒤 자동 삭제. 보낸 사람과 방장은 휴지통으로 지울 수 있어요.

막히면

"이미 가족방에 들어가 있어요"가 나와요새 가족방 만들기를 누른 폰이에요. 앱(해님 아이콘)을 지우고 초대 링크부터 다시 하세요. 갤럭시는 Chrome 설정 → 사이트 설정에서 이 사이트 데이터도 지워 주세요.

초대 코드가 안 돼요48시간이 지났거나 이미 쓴 코드예요. 방장에게 새 코드를 받으세요.

알림이 안 와요아이폰은 iOS 16.4 이상, 해님 아이콘으로 연 앱에서 "알림 켜기"를 눌러야 해요.
