사용 설명서

처음 시작할 때는 순서가 가장 중요해요. 방장 한 사람이 먼저 가족방을 만들고, 나머지 가족은 방장이 보낸 초대 코드로 들어와요.

1. 먼저 역할 정하기

방장
방장은 한 사람만

휴대폰을 잘 다루는 가족 한 명 (보통 자녀). 가족방을 만들고, 가족을 초대하고, 관리해요.

"새 가족방 만들기"를 누르는 사람
가족
나머지 가족 모두

부모님, 형제 등. 방장에게 초대 코드를 받아서 들어와요.

"초대 코드가 있어요"를 누르는 사람

방장이 먼저 가족방을 만들어야 해요. 가족이 먼저 앱을 열면 첫 화면에 "새 가족방 만들기"가 보이는데, 가족은 절대 누르지 마세요.

누르면 혼자만 있는 다른 가족방이 생기고, 그 폰으로는 초대 코드를 넣어도 "이미 가족방에 들어가 있어요"라고 나오며 우리 가족방에 들어올 수 없어요. (고치는 법: 7번 문제 해결)

방장2. 설치하고 가족방 만들기

  1. Safari로 앱 주소 열기: t19980519.github.io/whatsup카톡에서 열었다면 오른쪽 아래 ⋯ → "Safari로 열기".
  2. 공유 → 홈 화면에 추가 → 추가
  3. 홈 화면의 해님 아이콘으로 앱 열기아이폰은 꼭 이 아이콘으로 시작해야 해요. Safari 화면에서 만들면 아이콘 앱에서는 방장 권한이 이어지지 않아요.
  4. 새 가족방 만들기에서 가족방 이름, 내 이름(예: 큰아들), 사는 곳(나라·도시)을 적고 만들기
  5. 홈의 알림 켜기 → 허용아이폰 알림은 iOS 16.4 이상, 홈 화면 아이콘으로 연 앱에서만 받을 수 있어요.
  1. Chrome으로 앱 주소 열기: t19980519.github.io/whatsup카톡에서 열었다면 → "다른 브라우저로 열기" → Chrome.
  2. → 홈 화면에 추가 또는 앱 설치
  3. 홈 화면의 해님 아이콘으로 앱 열기
  4. 새 가족방 만들기에서 가족방 이름, 내 이름(예: 큰아들), 사는 곳(나라·도시)을 적고 만들기
  5. 홈의 알림 켜기 → 허용

방장3. 가족 초대하기

  1. 앱 위쪽 가족 편집 → + 가족 초대하기
  2. 초대 코드 6자리가 나오면 링크 복사 또는 보내기로 카카오톡에 보내기
  3. 카톡 메시지에 이렇게 함께 적어 주세요."앱을 설치하고 초대 코드가 있어요를 눌러서 코드 6자리를 넣어 주세요. 새 가족방 만들기는 누르지 마세요."
  4. 가족 한 사람마다 1~3번을 반복해요.
초대 코드는 한 사람만, 48시간 안에 쓸 수 있어요. 가족방은 방장 포함 최대 8명이에요. 부모님이 휴대폰을 어려워하시면 옆에 있는 가족이 대신 링크를 열어 들어가 드려도 돼요.

가족4. 초대 코드로 들어가기

"새 가족방 만들기"는 누르지 마세요. 첫 화면이 "새 가족방 만들기"로 보여도, 아래의 "초대 코드가 있어요"를 눌러야 해요.

  1. 카톡으로 받은 초대 링크를 눌러 Safari로 열기카톡 안에서 열렸다면 ⋯ → "Safari로 열기". 초대 코드 6자리는 따로 적어 두세요.
  2. 공유 → 홈 화면에 추가 → 추가
  3. 홈 화면의 해님 아이콘으로 앱 열기아이콘으로 열면 첫 화면이 "새 가족방 만들기"일 수 있어요. 당황하지 마세요.
  4. 화면 아래 초대 코드가 있어요를 누르기
  5. 초대 코드 6자리, 내 이름(예: 엄마), 사는 곳을 적고 가족방에 들어가기
  6. 홈의 알림 켜기 → 허용, 목소리를 보낼 때 마이크도 허용
  1. 카톡으로 받은 초대 링크를 눌러 Chrome으로 열기카톡 안에서 열렸다면 → "다른 브라우저로 열기". 링크로 열면 초대 코드가 자동으로 들어가 있어요.
  2. 그 화면에서 바로 내 이름(예: 엄마)과 사는 곳을 적고 가족방에 들어가기"새 가족방 만들기"가 보이면, 아래 초대 코드가 있어요를 누르고 코드 6자리를 직접 넣어 주세요.
  3. → 홈 화면에 추가 또는 앱 설치, 그다음부터는 해님 아이콘으로 열기
  4. 홈의 알림 켜기 → 허용, 목소리를 보낼 때 마이크도 허용

모두5. 매일 쓰는 법

안부 묻기

  1. "누구의 안부를 물어볼까요?"에서 가족 한 명 또는 가족 모두를 누르기얼굴 아래에 그곳의 지금 시각이 보여요. 한밤중인지 확인하세요.
  2. 음성 없이 간단히 물어보기: 누르면 바로 "별일 없지?"가 가요.
  3. 간단한 음성으로 물어보기: 누르고 말한 뒤 다시 누르면 보내져요.1분이 되면 자동으로 보내져요. 버튼 아래에 "받는 사람"이 보여요.

안부에 답하기

누가 안부를 물으면 홈 맨 위에 별일 없어요 해님이 나타나서 답할 때까지 통통 움직여요. 해님을 터치하면 끝이에요. 보낸 사람 소식에 "✓ 별일 없대요"가 떠요.

휴대폰 설정에서 "동작 줄이기"가 켜져 있으면 해님이 움직이는 대신 빛이 깜빡여요.

소식 보기

[엄마]가 가족 모두에게 안부를 물었어요.회색: 안부 기록
[동생]한테 받은 음성 안부분홍: 받은 목소리 (▶ 눌러서 듣기)
[엄마]에게 보낸 나의 음성 안부파랑: 내가 보낸 목소리
목소리는 90일이 지나면 자동으로 지워져요. 안부 기록과 목소리는 보낸 사람과 방장이 휴지통 버튼으로 언제든 지울 수 있어요. 한 사람에게 보낸 목소리는 두 사람만 들을 수 있어요.

모두6. 가족 편집

  1. 내 사진 넣기: 가족 편집 → 내 이름 누르기 → 사진 넣기가족들이 이름 대신 얼굴을 보고 고를 수 있어요.
  2. 이름·사는 곳 바꾸기: 가족 편집 → 이름 누르기
  3. 안부 소리: 내 목소리로 "별일 없지?"(5초)를 녹음해 두면, 안부를 받은 가족이 앱을 열 때 그 목소리가 들려요. 이 폰에서 소리 켜기·끄기도 여기서 해요.
  4. 새 버전 받기: 가족 편집 맨 아래 업데이트화면 맨 아래 "v1.○"으로 지금 버전을 확인할 수 있어요.
  5. 방장만 가족 내보내기: 가족 이름 누르기 → 내보내기

7. 이럴 땐 이렇게

가족이 실수로 "새 가족방 만들기"를 눌렀어요

그 폰은 혼자만 있는 다른 가족방에 들어가 있어서 초대 코드가 먹히지 않아요. 앱을 처음 상태로 되돌린 뒤 다시 들어가면 돼요.

아이폰

  1. 홈 화면의 해님 아이콘을 길게 눌러 앱 삭제
  2. 방장이 보낸 초대 링크를 Safari로 다시 열고 홈 화면에 추가
  3. 아이콘으로 열고 "초대 코드가 있어요" → 코드 입력

갤럭시

  1. 해님 아이콘을 길게 눌러 삭제(제거)
  2. Chrome → → 설정 → 사이트 설정 → 모든 사이트 → t19980519.github.io → 삭제(데이터 지우기)
  3. 초대 링크를 Chrome으로 다시 열고 들어가기

그래도 안 되면 방장에게 새 초대 코드를 받아 다시 해 보세요.

초대 코드를 넣었는데 안 돼요

초대 코드는 48시간이 지나거나 한 번 쓰면 더 이상 쓸 수 없어요. 방장에게 새 코드를 부탁하세요. 가족방이 이미 8명이면 더 들어올 수 없어요.

"이미 가족방에 들어가 있어요"가 나오면 위의 "실수로 새 가족방 만들기를 눌렀어요"를 보세요.

알림이 안 와요

아이폰: iOS 16.4 이상이어야 하고, Safari가 아니라 홈 화면 아이콘으로 연 앱에서 "알림 켜기"를 눌러야 해요. 설정 → 알림 → 별일없지에서 허용돼 있는지 확인하세요.

갤럭시: 설정 → 애플리케이션(앱) → 별일없지(또는 Chrome) → 알림을 켜 주세요.

해님이 안 보이거나 안 움직여요

해님은 안부를 받은 사람 폰에만, 아직 답하지 않았을 때만 나타나요. 보낸 사람 폰에는 소식에 기록만 생겨요.

버전이 오래됐다면 가족 편집 → 업데이트를 눌러 주세요. "동작 줄이기"가 켜진 폰에서는 움직이는 대신 빛이 깜빡여요.

휴대폰을 바꿨어요

가족: 방장에게 새 초대 코드를 받아 새 폰에서 다시 들어가세요. 방장은 예전 폰의 이름을 가족 편집에서 내보내 주세요.

방장: 지금은 방장 권한을 다른 폰으로 옮기는 기능이 없어요(준비 중). 새 폰으로 바꾸기 전에 개발자에게 먼저 알려 주세요.
